# 李若天英语训练营

给英语基础还比较弱的上海初三学生用的词汇练习。打开就能练：先看见英文，自己说出或写出中文意思，马上知道对不对。答错的词会更快再出现。

不登录，没有服务器。进度只留在这台浏览器里。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端里给出的地址（默认 `http://127.0.0.1:47321`）。手机和电脑在同一个网络时，也可以用终端里的局域网地址。

打包成静态文件：

```bash
npm run build
```

结果在 `dist/`。用 `npm run preview` 可以在本地看打包后的页面。

检查记忆算法和判分：

```bash
npm run check
```

## 怎么练

一轮默认 20 个词，也可以选 10 或 30。练完可以马上再来一轮，没有「今天只能练 30 个」的限制。

每一轮先放**已经到期**的词，不够再按词库顺序补新词。词库按使用频率从高到低排列，最常见的词先出现。

页面上先给英文和读音，单词一出现会自动读一次。想再听可以点「听发音」。然后写出中文，或点「说它的意思」（浏览器支持时）。写对一个主要意思就算对，比如「快的」和「迅速的」都可以。多写的「的」可以不写。实在想不起来，点「我还不会」，这一次记为没对上，然后看答案。

## 记忆方法

用的是**简化 SM-2**（间隔重复），再加上同一轮里的马上再练。

- 答对记 4 分，答错记 1 分。熟练度从 2.5 起，按 SM-2 的公式更新，最低 1.3：`EF + (0.1 − (5−q) × (0.08 + (5−q) × 0.02))`。
- 第一次答对：1 天后再见。
- 再连续答对一次：6 天。
- 之后每次答对：间隔大约等于上次间隔 × 熟练度（四舍五入，至少 1 天）。
- 答错：连续答对次数清零，间隔清零，这个词**马上到期**。下一轮练习会把它排在新词前面。经典 SM-2 答错后要再等 1 天，这里改成马上再练，方便基础较弱的同学。
- 同一轮里，答错的词会在大约 3 个词之后再出现，最多再练 2 次。如果这次答对了，就按「答对」重新计算（通常是 1 天后）。

错词本不是一张只放着看的表。曾经答错、还没连续答对 2 次的词都算「还没稳住」。它们到期后会自动进练习；也可以打开错词本提前复习，提前答对同样会计入上面的间隔。连续答对 2 次后，移到「已找回」。

## 进度存在哪里

浏览器的 `localStorage`，键名是 `chusan-en-vocab-v1`。里面有每张卡片的熟练度、间隔、到期时间、连续答对次数和答错次数，以及没做完的一轮。

刷新页面不会丢。换浏览器、换设备，或清除这个网站的数据，进度会消失。没有账号，也没有上传。

## 词库

`src/data/words.json` 里是中考常考词，按语料库词频从高到低。当前一共 1548 个。

来源：

- [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)（MIT）里带中考标签 `zk` 的词条、音标和中文释义
- 词表整理自 [cd155/collins-vocabulary](https://github.com/cd155/collins-vocabulary)（MIT），它本身也由 ECDICT 生成

高频词的「常考意思」、近义说法和短例句，按初三、基础较弱的学生又整理过一层。读音是词典音标换成接近国际音标的提示，个别词可能和课本不完全一样。这不是上海牛津教材的扫描件，所以个别课本专有词可能不在里面。

许可说明见 `THIRD_PARTY_NOTICES.md`。

以后加词：往 `words.json` 的 `words` 数组里追加对象，字段至少要有 `id`、`word`、`phonetic`、`meanings`、`accept`。`id` 用小写且不要重复。希望早点学到的词，放在数组更靠前的位置。也可以重新运行：

```bash
python3 scripts/build-words.py /path/to/collins.json src/data/words.json
```

## 语音

- **听发音**：使用浏览器的 Web Speech Synthesis，语言是英语。练习时单词出现会自动读一次；「听发音」用来再听一遍。部分手机会晚半秒才出声。
- **说它的意思**：使用 Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`），语言是中文。识别出的字会填进输入框，可以改完再提交。
- **安卓 Chrome**：两项通常都能用。请允许麦克风。用 `localhost` 打开时，浏览器会把它当成安全页面。
- **iPhone / iPad**：系统浏览器经常没有语音识别，「说它的意思」会提示改用打字。开始练习后的第一次朗读会跟着点击触发；若没有声音，可再点「听发音」。打字练习不受影响。
- 识别失败、没网，或用户拒绝麦克风时，页面会说明原因，并继续让学生打字。

## 不包含的东西

没有登录、没有后端、没有统计、没有第三方 Cookie。不会把练习数据发出去。
